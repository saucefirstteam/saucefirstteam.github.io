About UNIDOT

기업정보

Security from data to action.

유니닷(UNIDOT)은 기업 데이터 보호와 AI 실행 통제를 위한 보안 기술 기업입니다. 민감정보의 저장·전송, 문서의 근거 확인, 에이전트의 권한·승인을 업무 흐름에 연결합니다.

Company overview

업무 흐름에 맞춘 보안

데이터가 어디에 보관되고 어떤 조건에서 사용되는지, AI가 어떤 권한으로 실행되는지를 확인합니다. 암호화와 접근 통제, 원문 추적과 실행 기록을 연결해 기업의 자료와 업무를 보호합니다.

Technology focus

보호 대상에 맞는 기술

저장 데이터, 문서 근거, 실행 권한과 거래 상태를 각각의 보안 경계로 다룹니다.

01/

Data Boundary Protection

SQLCipher 암호화와 SecureStore 키 분리, Presidio 탐지·마스킹으로 고객정보와 업무 문서를 보호합니다. 외부 AI 전송에는 자료와 목적지의 허용 범위를 적용합니다.

기술 자세히 보기
02/

Grounded Document AI

HWP/HWPX 문서의 원문 위치·판본을 연결하고 규칙 점검과 로컬 AI로 검토를 지원합니다. 답변의 인용 근거는 원문과 대조합니다.

기술 자세히 보기
03/

Agent Authorization & Control

OPA 정책과 MCP 도구별 권한 검사로 모델 밖에서 자료 접근과 실행 범위를 통제합니다. 승인 대상·판본과 실행 기록을 함께 확인합니다.

기술 자세히 보기
04/

Transaction Integrity & Recovery

멱등키와 판본·처리 기록으로 거래 요청과 결과를 대조합니다. 결과가 불명확하면 자동 재전송을 차단하고 이전 상태를 확인해 복구 조건을 정합니다.

기술 자세히 보기
05/

Software Supply Chain Security

SLSA와 slsa-verifier로 의존성·MCP 구성요소·배포 산출물의 출처·서명·해시를 확인합니다. 검증 기록을 배포 대상과 판본에 연결합니다.

Industry scope

산업별 적용 범위

의료·보험·통신·모빌리티·건설·유통·기업 AI의 문서·데이터·운영 업무를 적용 분야로 다룹니다. 문서 업무에는 원문과 판본, 운영 업무에는 접근 권한과 승인·처리 상태를 연결합니다.
