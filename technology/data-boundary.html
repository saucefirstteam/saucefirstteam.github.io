암호화 저장·전송 통제

고객정보와 업무 문서는 저장할 때와 외부로 보낼 때 각각 확인할 조건이 있습니다. 유니닷은 암호화·키 분리·민감정보 마스킹과 전송 범위 관리로 데이터를 보호합니다.

보호 대상
고객정보와 업무 문서, 임시파일·캐시·로그의 민감정보를 다룹니다.
사용 중인 방식
암호화·키 분리·마스킹을 적용하고 저장 위치와 외부 전송 조건을 관리합니다.
확인할 결과
마스킹 결과와 실제 전송 내용, 보관·삭제·복구 조건을 확인합니다.

01/

저장 데이터 암호화

저장 데이터를 암호화하고 암호화 키는 별도 보관 경계로 분리합니다. 평문으로 대체 저장하지 않는 조건을 적용하며 키의 생성·사용·복구·삭제와 임시파일을 함께 검토합니다. 저장 암호화와 외부 전송 여부는 각각 확인합니다.

02/

민감정보 탐지·마스킹

개인정보와 산업별 식별자를 탐지하고 마스킹합니다. 한국어 표현과 업무 문서 형식에 맞춰 평가 항목을 구성하고, 업무에 필요한 정보와 보호할 정보가 어떻게 구분되는지 확인합니다.

03/

외부 전송 범위 관리

전송할 데이터, 목적지와 사용 목적의 허용 범위를 정합니다. 로컬 AI에도 외부 송신 허용 목록과 API 접근 조건을 적용하고 캐시·로그를 점검합니다. 실제 전송 경로와 기록에 남는 내용은 저장 위치와 별도로 확인합니다.

04/

보관·삭제·복구 조건

데이터의 계정과 처리 목적, 보관 기간에 맞춰 저장·전송 조건을 정합니다. 삭제·복구, 이전 버전의 재사용과 처리 중 오류에 대한 기준을 두고 변경된 조건이 이후 요청에 반영되는지 확인합니다. 확인한 데이터 목록과 저장·전송·접근 조건을 기록해 이후 변경 사항을 대조합니다.
