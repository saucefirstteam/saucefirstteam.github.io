Data Boundaries

암호화 저장·전송 통제

데이터 보안은 자료가 어디에 저장되고, 누가 읽으며, 어떤 내용이 외부로 나가는지를 구분하는 데서 시작합니다. 유니닷은 저장 암호화와 키 분리, 민감정보 탐지·마스킹, 외부 전송 통제를 함께 사용합니다.

Encrypted storage

SQLCipher로 저장 데이터를 암호화하고 SecureStore로 키의 보관 경계를 분리합니다. 평문 대체 저장을 허용하지 않는 조건을 적용하며, 키의 생성·사용·복구·삭제와 임시파일을 함께 검토합니다. 암호화 저장과 외부 전송 여부는 각각의 처리 경계로 다룹니다.

Sensitive data handling

Presidio를 사용해 개인정보와 산업별 식별자의 탐지·마스킹을 처리합니다. 한국어 표현과 업무 자료의 형식에 맞춰 평가 항목을 구성하고, 마스킹 결과가 업무상 필요한 정보와 보호할 정보를 어떻게 구분하는지 확인합니다.

Controlled egress

외부 AI 연결에는 전송할 자료, 목적지와 사용 목적의 허용 범위를 적용합니다. llama.cpp의 네트워크 경계에는 외부 송신 허용 목록, API 접근 조건과 캐시·로그 점검을 연결합니다. 저장 위치를 정한 뒤에도 실제 전송 경로와 기록에 남는 내용을 따로 확인합니다.

Lifecycle checks

저장·전송 조건은 자료의 계정, 처리 목적과 보관 수명에 연결합니다. 삭제와 복구, 이전 판본의 재사용, 처리 중 오류에 대한 기준을 정하고 변경된 조건이 이후 요청에 반영되도록 확인합니다.
