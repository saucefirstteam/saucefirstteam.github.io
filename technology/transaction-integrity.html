거래 상태 확인·복구

거래 무결성·중복 실행 억제

거래 상태 확인·복구는 통제의 하위 기능입니다. 처리 뒤 응답이 끊기면 재요청이 중복 처리로 이어질 수 있어 요청 식별자와 대상 버전, 이전 처리 기록으로 현재 상태와 복구 조건을 확인합니다.

01/

재시도할 요청의 식별

재시도할 요청의 본문·멱등키·기한을 고정합니다. 같은 작업의 재요청과 새로운 작업을 구분하고 대상 ID와 현재 버전을 검사합니다. 호출 전에 시도 기록을 저장해 이후 결과가 어떤 요청에서 나왔는지 확인합니다.

02/

응답과 최신 상태 대조

처리 확인 응답의 대상 ID와 다음 버전을 확인합니다. 재고·견적 등 관련 상태가 응답과 일치하는지 살피고 오래된 조회 결과가 최신 거래 상태를 덮지 않도록 반영 조건을 둡니다.

03/

불명확한 결과의 확인

성공·실패를 확인할 수 없는 결과는 불명확한 상태로 보존합니다. 자동 재전송을 차단하고 이전 실행의 확인 기록으로 결과를 정리합니다. 복구 중에도 기존 견적과 근거, 이전 실행 이력을 유지하는 조건을 적용합니다.

04/

중단·응답 유실 점검

동시 요청, 처리 전후 중단과 응답 유실을 검증 항목으로 구성합니다. 중복 실행 억제와 데이터 보존, 복구 후 최신 상태 반영을 함께 확인하고 각 검증 환경과 버전을 기록합니다. 처리 기록과 예외·복구 기준을 남겨 재시도 여부를 판단합니다.
