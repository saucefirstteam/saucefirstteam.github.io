Software Supply Chain

소프트웨어 공급망 보안

업무 데이터의 보호는 실행되는 소프트웨어의 공급 경로와도 연결됩니다. 유니닷은 SLSA와 slsa-verifier를 사용해 의존성, MCP 구성요소와 배포 산출물의 출처·서명·해시를 확인합니다.

Build provenance

배포할 파일이 예상한 소스와 빌드 경로에서 만들어졌는지 출처 정보를 대조합니다. 산출물과 연결된 증거를 확인하고 적용할 빌드, 저장소와 판본을 명시합니다.

Artifact verification

서명·해시와 출처 정보를 확인해 검증한 파일과 실제 배포 대상이 일치하는지 점검합니다. 확인할 수 없는 정보와 검증 결과를 구분하고 배포 조건에 연결합니다.

Dependency boundaries

의존성과 MCP 구성요소의 공급 경로, 변경 판본과 실행 권한을 함께 다룹니다. 구성요소가 바뀌면 기존 검증의 적용 범위를 다시 확인하고 도구 접근·실행 정책과 연결합니다.

Release records

배포 판본, 산출물과 검증 기록을 연결해 변경 내용을 되짚을 수 있게 합니다. 공급망 검증의 범위를 출처와 산출물 일치에 두고, 기능 검증과 업무 권한 검사는 별도의 조건으로 관리합니다.
