문서 근거 확인

AI가 제안한 문서 해석은 원문에 비춰 검토해야 합니다. 유니닷은 HWP5·HWPX의 파일·쪽·항목 위치와 버전을 추적하고 규칙 기반 점검과 로컬 AI로 담당자의 확인을 돕습니다.

적용 대상
HWP5·HWPX 문서의 파일·쪽·항목과 원문 버전을 다룹니다.
사용 중인 방식
원문 위치와 인용을 대조하고 규칙 점검·로컬 AI로 검토를 돕습니다.
검토 항목
담당자가 AI 제안과 원문 사실을 구분하고 인용·버전·해석을 확인합니다.

01/

원문 위치와 인용 대조

문서의 필드와 항목에 파일·쪽·원문 구간을 표시하고 원본 해시와 버전을 유지합니다. 인용은 UTF-8 바이트 구간과 해시로 선택한 원문과 대조합니다. 처리 결과에 확인할 원문 위치를 두고 입력값을 다시 읽어 대조하며 출력 문서의 누락·잘림을 점검합니다.

02/

입력 문서의 처리 범위

파일 크기와 압축 해제 한도, XML 외부 엔티티 제한과 별도 실행 환경으로 문서를 파싱합니다. 입력 문서가 후속 AI 처리와 도구 실행에 영향을 주는 경계를 나누고 허용된 구조와 처리 범위를 확인합니다.

03/

규칙 점검과 로컬 AI

규칙으로 확인할 수 있는 누락·형식·불일치를 먼저 점검합니다. 로컬 AI의 해석은 검토할 후보로 두고 담당자의 문서 확인을 돕습니다. 외부 송신 허용 목록과 API 접근 조건, 캐시·로그 점검을 함께 적용합니다.

04/

담당자의 근거 확인

원문 위치의 일치와 해석의 타당성은 각각 확인합니다. AI 제안, 원문에서 확인한 내용과 검토자의 판단을 구분해 최종 판단을 돕습니다. 문서 버전이 바뀌면 해당 근거와 검토 조건을 다시 확인합니다.
