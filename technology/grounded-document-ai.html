Grounded Document AI

HWP/HWPX 원문 기반 문서 AI

AI가 문서를 해석한 결과를 확인하려면 답변이 어느 원문에서 나왔는지 되짚을 수 있어야 합니다. 유니닷은 HWP5·HWPX 문서의 구조와 파일·쪽·항목 위치를 연결하고 규칙 기반 점검에 로컬 AI를 보조로 사용합니다.

01/

Source mapping

문서의 필드와 항목을 파일·쪽·원문 구간에 연결하고 원본 해시와 판본을 유지합니다. 인용은 UTF-8 바이트 구간과 해시를 사용해 선택한 원문과 다시 대조합니다. 처리 결과에는 확인할 원문 위치를 함께 두고, 입력값을 다시 읽어 대조하며 출력 문서의 누락이나 잘림을 점검합니다.

02/

Isolated parsing

문서 파싱에는 파일 크기와 압축 해제 한도, XML 외부 엔티티 제한과 별도 실행 환경을 사용합니다. 입력 문서가 후속 AI 처리와 도구 실행에 영향을 주는 경계를 구분하고 허용된 구조와 처리 범위를 확인합니다.

03/

Local AI assistance

llama.cpp와 Gemma를 사용해 로컬 문서 처리 흐름을 구성합니다. 규칙으로 확인할 수 있는 누락·형식·불일치를 우선 점검하고, 모델의 해석은 검토할 후보로 둡니다. 외부 송신 허용 목록과 API 접근 조건, 캐시·로그 점검도 함께 적용합니다.

04/

Human review

원문 위치가 일치하는 것과 해석이 타당한 것은 각각 확인할 항목입니다. AI 제안, 원문에서 확인한 내용과 검토자의 판단을 구분하고 담당자의 확인과 최종 판단을 지원합니다. 판본이 바뀌면 연결된 근거와 검토 조건을 다시 확인합니다.
