홈 / 보안 기술

Agent Control

에이전트 권한·승인·실행 통제

모델이 작업을 제안하는 단계와 업무를 실제로 실행하는 단계에는 서로 다른 확인 조건이 필요합니다. 유니닷은 OPA 정책 판단과 MCP 도구별 권한 검사를 사용해 모델 밖에서 접근·실행 범위를 통제합니다.

Policy evaluation

MCP 도구별 최소 권한을 적용하고 요청의 계정, 현재 역할, 대상과 토큰의 적용 대상을 확인합니다. OPA의 정책 판단은 모델 응답과 분리해 평가합니다. 호출 전에 권한과 승인 조건을 검사하고 일치한 조건에 맞춰 실행 범위를 정합니다.

Bound approvals

승인은 특정 대상, 결과물 해시, 판본과 승인 범위에 연결합니다. 내용이나 판본이 바뀌면 이전 승인을 그대로 이어 쓰지 않도록 재검사합니다. 현재 권한과 상태, 필요한 약관·동의 기록을 실행 조건에 함께 연결합니다.

Execution records

실행 전 시도 기록을 남기고 작업 키와 시도 번호로 요청을 연결합니다. 시작·완료·실패와 불명확한 결과를 구분해 기록하며, 이전 처리 결과를 확인하는 복구 흐름을 둡니다. 검토자는 원문 근거, 승인 대상과 처리 기록을 함께 확인합니다.

Research context

보안 기술을 검토하는 배경에는 OpenAI Trusted Access for Cyber 접근 승인 및 보안 연구 참여 경험이 있습니다. 이는 2026년 7월 개인 자격의 승인·참여 경험입니다.
