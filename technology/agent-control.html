에이전트 권한·승인·실행 통제

AI가 제안한 작업을 실제 업무에서 실행하려면 현재 권한과 사람의 승인을 확인해야 합니다. 유니닷은 모델 밖에서 역할·도구별 권한과 승인 조건을 검사하고 시도와 결과를 기록합니다.

01/

현재 역할과 권한 검사

도구별 최소 권한을 적용하고 요청의 계정, 현재 역할, 대상과 토큰의 적용 대상을 확인합니다. 정책 판단을 모델 응답과 분리해 평가하고 호출 전에 권한과 승인 조건을 검사합니다. 일치한 조건에 맞춰 실행 범위를 정합니다.

02/

대상·결과물에 묶인 승인

승인을 특정 대상, 결과물 해시, 버전과 승인 범위에 묶습니다. 내용이나 버전이 바뀌면 이전 승인을 그대로 쓰지 않도록 재검사합니다. 현재 권한·상태와 필요한 약관·동의 기록도 실행 조건으로 확인합니다. 원문 출처와 승인 대상을 검토한 기록을 실행 조건과 함께 보존합니다.

03/

실행 시도와 결과 기록

실행 전에 시도 기록을 남기고 작업 키와 시도 번호로 요청을 식별합니다. 시작·완료·실패와 불명확한 결과를 나눠 기록하며 이전 처리 결과를 확인하는 복구 흐름을 둡니다. 검토자는 원문 출처와 승인 대상, 처리 기록을 함께 확인합니다.
